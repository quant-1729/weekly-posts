# Stage 3: Solutions catalogue

What people use today to cope with the pains in Stage 1. Catalogue only, no scoring yet.

**Research caveat:** most sources found were vendor blogs and listings, not first-hand forum posts. Searches for Reddit threads mostly returned vendor articles. Treat the evidence as directional; real user interviews are still needed.

## Patterns worth noting

1. **Global tools are English-first and priced in USD.** India-specific vernacular tools exist but are small and unproven.
2. **Nobody owns "brand memory + vernacular + approval" together.** Each exists separately: Canva covers design, Planable approvals, Quillmo Hindi copy, Repurposr repurposing.
3. **Approval pain is well documented.** Dedicated tools exist, but they target agencies, not SMBs on WhatsApp.
4. **Generic AI output is the most-cited complaint.** The usual fix is manual (paste a voice document), which supports the brand-memory idea from Stage 2.
5. **Non-software fixes work for low volume.** Batching, fewer platforms and revision caps help, but break down at scale or in multiple languages.
